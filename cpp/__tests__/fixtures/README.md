# Test fixtures

Generated by `scripts/make-test-fixtures.sh` (needs ffmpeg with libx264). Do not
edit by hand; regenerate and commit all three together, because `reference.flv`
is compared byte for byte in `Golden.test.cpp`.

| File | Content |
|---|---|
| `video.h264` | 320x240, 30 fps, 2 s (60 frames), H.264 Constrained Baseline, no B-frames, one slice per frame, keyframe every 30 frames, SPS/PPS repeated before every IDR |
| `audio.aac` | AAC-LC 48 kHz stereo, ADTS with `protection_absent=1`, 2 s of a 440 Hz sine (94 frames) |
| `reference.flv` | `ffmpeg -c copy -fflags +bitexact` of both into FLV |

Timestamps the tests assign to frame *n*: video `round(n * 1000 / 30)`,
audio `round(n * 1024 * 1000 / 48000)`; these match FFmpeg's rounding, which
`Golden.test.cpp` checks.

Known FFmpeg-specific tags in `reference.flv` that the comparison skips:

- an AAC sequence header with an empty AudioSpecificConfig (`AF 00`) written
  before the `aac_adtstoasc` filter produced the real one (`AF 00 11 90`);
- the AVC end-of-sequence tag (`17 02 00 00 00`) written when the file is closed;
- the `onMetaData` script tag, whose fields are muxer specific.
